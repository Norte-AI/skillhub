## 当前边界与后续顺序

当前推荐PostgreSQL后端，允许多个HTTP/MCP进程共享，事务确保写一致性；旧JSON后备仍只支持一个写进程。API与CLI产物是通用内容包，暂存和服务端获取都不表示客户端已加载。

下一步依次补齐：三端原生市场安装与客户端加载验证 → Kimi 桌面个人市场登记接入 → 持久化与发布签名 → 市场后台与页面 → 三端新旧会话及完整故障验收。各任务以实际证据推进；目前没有任何一个真实客户端被标为“已验证注入”。
