# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Static HTML, CSS and JavaScript, served by the existing Node HTTP server. Delegated in implementation brief.
## Users
Personal users and small teams managing reusable agent skills and rule bundles.
## Product Purpose
Upload and review skills, publish immutable versions, install from a Git marketplace, and inspect device loading evidence.
## Operating Context
Chinese administrative interface; Codex Git marketplace installation is the current integration route. All data comes from existing HTTP APIs.
## Capabilities and Constraints
Local anonymous administration follows server access policy. Optional administrator credentials remain session-only. Client reports do not establish verified compatibility. Live client acceptance remains external to this interface.
## Product Principles
Show real server state. Keep release publication explicit. Preserve immutable history. Distinguish submitted evidence from verified loading.
## Open Decisions
Visual choices inferred from the delegated operating-UI brief: restrained daylight workspace, compact lists, blue action accent.
